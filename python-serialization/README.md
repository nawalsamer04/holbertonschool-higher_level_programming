# Python - Serialization

This project practices **serialization and deserialization** in Python using:
- **JSON** (dictionary <-> JSON file)
- **pickle** (custom class object <-> binary file)
- **CSV to JSON** conversion

## Files
- `task_00_basic_serialization.py`: save/load a dictionary using JSON
- `task_01_pickle.py`: `CustomObject` class with pickle `serialize()` / `deserialize()`
- `task_02_csv.py`: convert a CSV file into `data.json`

## How to run (examples)
Task 0:
```bash
python3 main_00_basic_serialization.py
