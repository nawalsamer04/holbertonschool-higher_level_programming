# Python - Abstract Classes and Interfaces

This project practices Python OOP concepts related to abstract base classes (ABCs), interfaces, and subclassing.

## Tasks
- **0. Abstract Animal Class and its Subclasses**
  - Create an abstract class `Animal` with an abstract method `sound()`.
  - Implement `Dog` and `Cat` subclasses that return `"Bark"` and `"Meow"` respectively.
