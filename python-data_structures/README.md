# Python - Data Structures: Lists, Tuples

This project covers the basics of Python data structures, focusing on
lists and tuples. It includes simple functions to manipulate and
display data structures following Holberton School coding standards.

## Learning Objectives
- Understand Python lists and tuples
- Iterate through lists
- Modify list elements
- Write reusable functions
- Follow Python coding conventions

## Tasks
- Print elements of a list
- Replace list elements
- Secure access to elements
- Work with tuples
