# Python - Server-Side Rendering

## Description
This project introduces server-side rendering using Python. It starts with a simple templating program that generates personalized invitation files from a text template and a list of attendees.

## Learning Objectives
- Understand basic string templating in Python
- Read from files and write to files
- Handle invalid input and missing data gracefully
- Generate output files dynamically

## Project Structure
- `task_00_intro.py`: Generates invitation files from a template and attendee data

## Requirements
- Python 3.x
- Allowed editors: `vi`, `vim`, `emacs`
- All files should end with a new line

## Usage
Example:

```bash
python3 task_00_intro.py
